会发生什么

  • 桌宠安装到 /Applications/DSH Pet.app
  • 自带形象和插件安装到 /Library/Application Support/DSH Desktop Pet/
  • 插件加入当前用户的 DSH desktop profile，并启用
  • DSH 会被退出并重新打开，桌宠自动出现

安装后

  • DSH 设置 → 桌宠：改显示、图标、换形象
  • 右键桌宠：换形象 / 自定义图标 / 打开 DSH / 退出
  • 新增形象放到 ~/.dsh-desktop-pet/pets/<id>/，设置页刷新即可

说明

v0.1 是开发者 beta，安装包未做 Developer ID 签名/公证；macOS 第一次可能会拦截，右键安装包 → 打开。数据只在本机使用。
