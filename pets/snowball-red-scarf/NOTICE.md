# 雪团 · 红围巾白狐

原创、非官方 DSH 桌宠包，按用户「戴红围巾的白色小狐狸」描述制作。
未使用第三方角色、商标、官方吉祥物或网络素材。

## 来源和制作

- 日期：2026-10-20。
- 图像：通过本机 Bailian CLI 的 `bl image generate` 调用 `qwen-image-2.0`，尺寸 1024×1024，seed 73421，关闭提示词扩写。
- 每个动作单独生成；向右跑有两个步态源图，向左跑由向右跑镜像。
- 图集处理：绿幕去底与边缘去色、RGBA 透明、尺寸和基线对齐、呼吸/倾斜/弹跳等二维补间；不是逐帧重新生成的手绘动画。
- 图集：1536×1872，8列×9行，单格192×208，有效帧数6,8,8,4,5,8,6,6,6，共57帧。
- 清单骨架来自本地 DSH `tools/import-codex-pet.py`；行为和气泡为本包定制。
- 完整生成提示词见 `PROMPTS.md`。

## 使用

把目录放入 `~/.dsh-desktop-pet/pets/` 后，在 DSH 设置 → 桌宠 → 形象 → 刷新，选择「雪团 · 红围巾白狐」。
点击挥手，拖动跳跃；待机20秒/35秒分别播放向右/向左跑动作，60秒挥手。
跑步是本包帧动画，是否在桌面移动由宿主引擎控制。
