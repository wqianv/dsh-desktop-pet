# DSH Desktop Pet v0.2.2

状态面板 UI 重做，直接覆盖升级 v0.2.1。

## 改进

- 面板改为 **shadcn/ui 风格**（Card / Badge / Button 的结构、间距、圆角、边框）
- 图标全部换成 **lucide SVG**：向下箭头、清除 × 都严格在按钮圆心
- 标题左侧改为垂直三色小灯，和右侧数字 badge 垂直居中对齐
- 收起状态改为一个独立的胶囊灯条：
  - 彩色状态圆点 + 数量
  - 圆点/数字在胶囊内居中
  - 点击胶囊重新展开
- 面板继续贴着宠物显示；气泡收进面板内部
- 只保留一个向下箭头，不再有最小化/关闭两个按钮

## 下载

- **推荐** `DSH-Desktop-Pet-v0.2.2-macos-arm64.pkg`
- 备用 `DSH-Desktop-Pet-v0.2.2-macos-arm64.zip`

直接覆盖安装 v0.2.1。
