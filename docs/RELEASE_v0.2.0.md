# DSH Desktop Pet v0.2.0

新增「会话状态面板」：桌宠头顶最多显示 7 个会话，完成/等待/失败/运行中用红绿灯圆点区分，方便提醒你 DSH 已经干完活。

## 下载

- **推荐** `DSH-Desktop-Pet-v0.2.0-macos-arm64.pkg`（双击安装，自动覆盖升级）
- 备用 `DSH-Desktop-Pet-v0.2.0-macos-arm64.zip`

## 新功能

- 桌宠上方显示会话状态面板（默认展开）
- 最多 7 个会话；不活跃的会话不显示
- 圆点：
  - 🟢 绿色：完成（OK）
  - 🟡 黄色：等你回答 / 需要确认
  - 🔴 红色：失败 / 出错
  - 🔵 蓝色：运行中
- 完成/失败的提醒保留到你手动清掉（点行末 × 或「清空已完结提醒」）
- 折叠成标题栏；隐藏后只有**新提醒**出现时才自动重新弹出
- 面板出现时窗口自动变高，宠物保持原位

## 安装/升级

1. 下载 `.pkg`
2. 保存好 DSH 里手头的东西（安装器会退出并重启 DSH）
3. 双击 pkg；第一次被 Gatekeeper 拦就右键 → 打开
4. 输入密码 → 安装
5. 安装器覆盖旧 app/插件并重启 DSH
