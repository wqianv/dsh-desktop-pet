# DSH Desktop Pet v0.1.2

小版本升级，直接覆盖安装 v0.1.1 / v0.1 即可。

## 下载

- **推荐** `DSH-Desktop-Pet-v0.1.2-macos-arm64.pkg`
  - 双击 → 输入密码 → 点「安装」，作为升级覆盖旧版本
- 备用 `DSH-Desktop-Pet-v0.1.2-macos-arm64.zip`

## 修复

- **不在前台时第一次点击即可拖动**：macOS 窗口启用 `acceptFirstMouse`，桌宠不是前台 app 时，第一次按住就能拖，不需要先点一下激活。
- 保留 v0.1.1 的 Retina 修复和安装器修复。

## 安装/升级

1. 下载 `.pkg`
2. 保存好 DSH 里手头的东西（安装器会退出并重启 DSH）
3. 双击 pkg；第一次被 Gatekeeper 拦就右键 → 打开
4. 输入密码 → 安装
5. 安装器覆盖旧 app/插件并重启 DSH，桌宠自动出现

- 未签名/未公证：第一次仍要右键打开
