# DSH Desktop Pet v0.2.1

会话状态面板的交互/布局改进，直接覆盖升级 v0.2.0。

## 下载

- **推荐** `DSH-Desktop-Pet-v0.2.1-macos-arm64.pkg`
- 备用 `DSH-Desktop-Pet-v0.2.1-macos-arm64.zip`

## 改进

- 面板下移，贴着桌宠显示，不再高高悬在窗口顶部
- 去掉「最小化 / 关闭」两个按钮，只保留一个向下箭头
- 点向下箭头收起成 **Codex 风格灯条**：一行彩色状态点，不占地方
- 收起后的灯条点一下即可重新展开
- 面板内的普通阶段/费用气泡收进面板内部显示，不再和标题/状态行重叠
- 窗口高度随面板/灯条自动调整，宠物位置保持不动

## 安装/升级

1. 下载 `.pkg`
2. 保存好 DSH 里手头的东西（安装器会退出并重启 DSH）
3. 双击 pkg；第一次被 Gatekeeper 拦就右键 → 打开
4. 输入密码 → 安装
5. 安装器覆盖旧 app/插件并重启 DSH
