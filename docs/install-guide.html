DSH Desktop Pet · First Install

把桌宠放到你的桌面上

这是给普通用户的首次安装指南。全程大约 3 分钟，只需要装一次；之后打开 DSH，桌宠会自动出现。

macOS · Apple Silicon v0.2.2 beta 无需 Rust / Xcode / Node
双击 .pkg→ 点「安装」→ 桌宠自动出现
pkg 是标准 macOS 安装器；安装器会自动放行 App、装 DSH 插件并重启 DSH。以后不用手动打开桌宠。
推荐 · 一个安装包

下载 .pkg，双击安装

双击 DSH-Desktop-Pet-v0.2.2-macos-arm64.pkg → 输入密码 → 点「安装」。安装器会自动装好 App、7 个形象和 DSH 插件，并重启 DSH。装完回到本页第 4 步验收即可。

如果下载的是 zip：双击里面的 Install DSH Pet.command，同样点两次「继续」。

开始前，先确认

  • Mac 是 Apple Silicon（M1/M2/M3/M4）
  • 已经安装并登录 DSH
  • 下载了 DSH-Desktop-Pet-v0.2.2-macos-arm64.zip
  • 知道解压后的文件夹要放在哪（建议 ~/Applications）

你会得到什么

一只悬浮在 macOS 桌面上的桌宠：随 DSH 的思考/工具/等待/完成切换动画，可点击、拖拽、换形象，并显示费用和余额气泡。Dock/菜单栏图标默认隐藏。

不需要安装 Rust、Xcode 或 Node。也不会上传任何数据；状态/余额只走本机 DSH 服务。
1

备用方案：解压 zip，并放到固定位置

如果你下载的是 .pkg，这一页可以直接跳到第 4 步验收。

DSH-Desktop-Pet-v0.2.2-macos-arm64/ ├── DSH Pet.app ← 桌宠本体 ├── pets/ ← 自带形象 ├── dsh-launcher/ ← DSH 插件 ├── INSTALL.md ├── install-guide.html └── ...
  1. 双击 zip 解压。
  2. 把整个文件夹拖到一个以后不会随手删的位置，例如 ~/Applications/。
  3. 不要只把 DSH Pet.app 单独拿走——它要和 pets/、dsh-launcher/ 待在一起。
检查点：文件夹里能看到 DSH Pet.app、pets、dsh-launcher 三样东西。
2

第一次打开桌宠，过 Gatekeeper

v0.1 还没做 Apple 公证，macOS 第一次会拦。只需要处理这一次。

推荐：右键 → 打开

  1. Finder 里找到 DSH Pet.app。
  2. 右键（或 Control + 点击）→ 打开。
  3. 弹窗里再点一次 打开。
  4. 看到桌宠出现后，先右键它 → 退出，避免和插件的自动启动打架。

如果还是被拦

  1. 打开 系统设置 → 隐私与安全性。
  2. 页面底部点 仍要打开，输入密码。
  3. 或确认来源可信后，在解压目录执行：
xattr -dr com.apple.quarantine \
  "你的解压目录/DSH Pet.app"
open "你的解压目录/DSH Pet.app"
⚠️ 这一步是 v0.2.0 未签名/未公证导致的；正式签名版不会出现。不要从不可信来源下载后强行放行。
检查点：桌宠出现在屏幕右下角。然后先退出它，继续第 3 步。
3

给 DSH 装插件（只装一次）

插件负责自动拉起桌宠、传状态、提供设置页。

  1. 打开 DSH。
  2. 进入 设置 → 插件。
  3. 点 添加插件，选择 本地目录 / Local directory。
  4. 选中解压文件夹里的 dsh-launcher 文件夹（不是它的上一级）。
  5. 安装完成后确认插件是 已启用 状态。
  6. 完全退出 DSH：Cmd + Q，再重新打开。

4

确认一切正常

打开一次设置页，顺手试几个开关。

  1. DSH 设置 → 桌宠：切换 Dock/菜单栏图标、上传图标、切换「形象」。
  2. 鼠标移到桌宠上：可以点击/拖动；移开后点击穿透。
  3. 右键桌宠：更换形象 / 设置 / 自定义图标 / 打开 DSH / 退出。
  4. 发一条消息：桌宠随思考、调用工具、等待确认、完成切换动画；回合结束出现费用气泡。
检查点：设置页能打开、形象能 hot swap、右键菜单正常、费用气泡出现。到这里就装好了。
5

可选：添加自己的形象

把宠物包放进用户目录，设置页刷新即可。

  1. 把新的宠物包目录放到 ~/.dsh-desktop-pet/pets/<id>/。
  2. DSH 设置 → 桌宠 → 形象 → 点 刷新。
  3. 下拉选择新形象，约 1 秒热切换。
想做全新形象？把 skills/create-dsh-pet/SKILL.md 交给 Codex / DSH agent，并说明角色、动作和许可；规范在 docs/PET_PACK_SPEC.md。

常见问题

DSH 起来了，但桌宠没出现
  1. 插件是否启用？
  2. 是否完全退出并重启过 DSH？
  3. 安装时选的是不是 dsh-launcher？
  4. 第 2 步有没有完成？未签名 app 第一次可能被 Gatekeeper 挡住。
  5. 手动打开一次 app 看是否报错。
  6. 在解压目录运行 bash scripts/doctor.sh。
提示「无法验证开发者」

回到第 2 步右键打开，或系统设置 → 隐私与安全性 → 仍要打开。v0.2.0 未公证导致，正式签名版不会有。

设置里没有「桌宠」页面

确认插件已启用并完全重启 DSH；确认安装的是 dsh-launcher 文件夹。

有桌宠，但没有费用/余额

费用需要 DSH 正常产生会话事件，聊一轮再看；余额需要在 DSH 登录 DeepSeek 账户。未登录/离线不影响动画和互动。

卸载

  1. DSH → 插件 → 停用/移除 dsh-desktop-pet-launcher
  2. 完全退出 DSH
  3. 右键桌宠 → 退出
  4. 删除解压文件夹
  5. 可选清理：
    rm -rf ~/.dsh-desktop-pet
每次打开 DSH 都要手动开桌宠吗？不用。只有首次安装/首次批准 App 是一次性的；之后由插件自动启动。
