# DSH Desktop Pet v0.3.1

给自动散步等休闲功能加了开关，直接覆盖升级 v0.3.0。

## 新增开关

**DSH 设置 → 桌宠 → 休闲功能**，也可以右键桌宠 → 设置：

- **自动散步**：DSH 空闲时在桌面随机走动
- **挂机小动作**：发呆、睡觉、伸懒腰等无操作时的随机动作
- **快捷键召唤**：`Option+Shift+P` 标记鼠标位置，桌宠跑过去
  - 关闭后快捷键注册仍存在，但不会触发移动

改动即时生效；自动散步进行中关闭会取消当前移动。
