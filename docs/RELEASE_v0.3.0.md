# DSH Desktop Pet v0.3.0

桌面互动基础版：桌宠可以离开右下角，在桌面上跑动。

## 新增

- **快捷键标记位置**：`Option + Shift + P` 标记当前鼠标位置，桌宠会跑过去
  - 已允许窗口顶边延伸到屏幕外，所以标记屏幕上半部分也能到达
- **自动散步**：DSH 空闲时，桌宠会每隔约 24 秒在桌面范围内随机走动
  - 用户鼠标停在桌宠上 / 正在拖动时不会自动走
  - 手动拖动会取消当前移动
- 走动时自动切换 walk-left / walk-right 动画
